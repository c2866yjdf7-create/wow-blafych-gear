# WoW — Блафыч: центр прогресса

Автоматический трекер персонажа **Блафыч · EU / Гордунни**. Источник — официальный публичный API [Raider.IO](https://raider.io/ru/characters/eu/gordunni/%D0%91%D0%BB%D0%B0%D1%84%D1%8B%D1%87).

## Начни отсюда

- **[Панель Блафыча — DASHBOARD.md](./DASHBOARD.md)** — экипировка, рейтинг, рейды и ближайшие цели.
- **[Приоритеты экипировки — gear-advice.md](./gear-advice.md)** — что менять, что сохранять, где искать замену и почему.
- **[Маршрут ключей — next-keys.md](./next-keys.md)** — все восемь подземелий второго сезона с актуальными закрытиями.
- **[Ручное обновление и история запусков — GitHub Actions](https://github.com/c2866yjdf7-create/wow-blafych-gear/actions/workflows/update-gear.yml)**.
- **[Веб-панель (index.html)](./index.html)** — адаптивная версия для GitHub Pages (см. инструкцию ниже).

## Обновление

GitHub Actions **каждые три часа** запускает `scripts/update_gear.py`, `scripts/build_reports.py` и `scripts/analyze_gear.py`.

Для обновления прямо сейчас: **Actions → Update Blafych data → Run workflow → main → Run workflow**.

В каждом отчёте указано, когда Raider.IO обновил данные (`source_last_crawled_at`). Дата `fetched_at_utc` — когда наш скрипт скачал информацию. **Это разные вещи**. Если Raider.IO не обновился, новый запуск GitHub сам по себе не делает сведения об экипировке свежее.

Если API не отдал экипировку, новая выгрузка не заменяет старый `gear.json`. Запуск GitHub Actions будет помечен ошибкой.

## Как включить красивую веб-панель

Для работы `index.html` как сайта нужно **один раз** включить публикацию GitHub Pages:

1. Открой [Settings → Pages](https://github.com/c2866yjdf7-create/wow-blafych-gear/settings/pages).
2. В блоке **Build and deployment** выбери **Deploy from a branch**.
3. Укажи **main** и **/(root)**, затем нажми **Save**.
4. После успешного опубликования адрес обычно будет `https://c2866yjdf7-create.github.io/wow-blafych-gear/`.

Пока Pages не включён, полноценная панель уже доступна через [DASHBOARD.md](./DASHBOARD.md). Сама HTML-страница и все исходные данные находятся в этом репозитории.

## Если таланты не видны

Raider.IO может не отдавать билд Блафыча. Это **не** означает, что талантов у него нет.

Чтобы заполнить их вручную:

1. В WoW открой **Таланты → Экспортировать набор** и скопируй длинную строку.
2. Открой [talent-import.txt](./talent-import.txt), нажми ✏️ и вставь строку после `BLIZZARD_TALENT_STRING=`.
3. Сохрани изменение — GitHub Actions автоматически пересоберёт отчёты.
4. При изменении билда экспорт придётся обновить вручную. В `talents.json` будет указан источник `manual_import`.

Если Raider.IO позднее начнёт возвращать актуальные таланты, они получат приоритет над ручным экспортом.

## Важные ограничения

- **Великое хранилище:** API не предоставляет достоверное состояние ячеек. Недельные ключи в `weekly.json` — *не* полный счётчик хранилища.
- **Валюты, сумки, личный ключ, квесты:** без аддона и отдельной выгрузки автоматически не определяются.
- **Таланты:** в текущем профиле автоматический ответ API может быть пустым.
- **Анализ экипировки:** список ориентировочный, без индивидуальной симуляции DPS. Для энха учитываются сохранение 4-сета, защита крафтовых вещей и известные полезные триньки. При смене конкретной триньки на неизвестную автоматический совет по ней убирается, чтобы не делать ложных выводов. Цели обновляются по вручную проверенным гайдам, а НЕ по автоматической мета-выгрузке. После крупного патча рекомендации следует проверить заново.
- **Зачарования:** пустое поле не означает, что предмет точно нужно зачаровать; оценка BiS требует сверки с актуальной метой.
- **История экипировки:** фиксируется только с момента подключения трекера, между проверками можно пропустить несколько смен.
- **Планировщик M+:** отмечает недостающие прохождения и рекомендует постепенный рост сложности, но не предсказывает реальную сложность группы или точную прибавку рейтинга.

Скрипты используют только общедоступные игровые данные; никаких токенов Battle.net в репозитории нет. API принадлежит [Raider.IO](https://raider.io/).
